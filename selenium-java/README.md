# Selenium Java Automation Samples

This module contains sample Selenium automation scripts written in Java, demonstrating real-world QA automation practices.

## What this covers
- Web UI automation using Selenium WebDriver
- Java-based test structure
- Element identification and interaction
- Basic validation and assertions
- Clean, readable automation code suitable for interviews

## Tools & Technologies
- Java
- Selenium WebDriver
- Maven (project structure reference)
- Chrome browser (example)
